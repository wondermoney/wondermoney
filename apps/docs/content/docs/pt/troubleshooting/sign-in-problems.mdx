## Sintomas

Esta página ajuda quando não é possível iniciar sessão ou quando a autenticação falha.

Sintomas comuns:

- A palavra-passe não é aceite
- O email não é reconhecido
- O segundo fator falha
- A sessão fica presa na página de login

## O que verificar

Confirma:

- Se o email está correto
- Se o método de início de sessão correto está a ser usado
- Se a palavra-passe foi escrita sem erros
- Se o código de autenticação ainda é válido

## O que tentar

Tenta estes passos:

1. Reintroduz as credenciais com cuidado.
2. Usa a recuperação de palavra-passe, se disponível.
3. Limpa o formulário e volta a tentar.
4. Testa noutro navegador.

## Quando contactar o suporte

Contacta o suporte se:

- Não for possível repor o acesso
- O código de 2FA não funcionar
- A conta existir mas continua a bloquear o acesso
