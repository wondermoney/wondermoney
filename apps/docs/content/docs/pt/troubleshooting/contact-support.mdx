## Sintomas

Contacta o suporte quando não conseguires resolver um problema com os passos habituais.

Situações típicas:

- O erro continua a aparecer
- A conta mostra dados inconsistentes
- Precisas de ajuda com cobrança ou plano
- Um fluxo essencial está bloqueado

## O que verificar

Antes de escrever, confirma:

- Se já consultaste o artigo certo
- Se o problema é repetível
- Se existem capturas de ecrã ou mensagens de erro
- Se o problema afeta mais do que um navegador ou dispositivo

## O que tentar

Tenta primeiro:

1. Atualiza a página.
2. Sai e entra novamente.
3. Repete o passo com a ligação estável.
4. Recolhe os detalhes do erro.

## Quando contactar o suporte

Contacta o suporte quando:

- Precisares de intervenção na conta
- Houver risco de perda de dados
- O problema envolver segurança

Podes contactar o suporte da WonderMoney por email para [support@wonder.money](mailto:support@wonder.money).

Inclui sempre:

- A área da aplicação onde aconteceu
- A hora aproximada
- A mensagem de erro exata
- O que esperavas ver
