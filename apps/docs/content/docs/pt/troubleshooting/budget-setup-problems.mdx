## Sintomas

Esta página é útil quando o orçamento não guarda, mostra valores errados ou não permite continuar.

Sinais comuns:

- O orçamento não é criado
- As categorias não aparecem como esperado
- Os totais parecem incorretos
- O progresso mensal não atualiza

## O que verificar

Antes de voltar a tentar, confirma:

- Se todas as categorias necessárias estão selecionadas
- Se os valores somam corretamente
- Se o mês e o ano estão certos
- Se há limites obrigatórios em falta

## O que tentar

Tenta estes passos:

1. Guarda novamente após rever os valores.
2. Reduz o número de categorias e testa de novo.
3. Confirma se o orçamento está ligado ao mês certo.
4. Reabre a página e verifica se os dados persistem.

## Quando contactar o suporte

Contacta o suporte se o erro impedir a criação do orçamento ou se os dados forem alterados sem explicação.
