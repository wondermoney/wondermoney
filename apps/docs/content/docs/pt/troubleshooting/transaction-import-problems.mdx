## Sintomas

- Um ficheiro de importação é rejeitado.
- A importação termina mas as transações não aparecem.
- Algumas linhas são ignoradas.
- As datas, os montantes ou as descrições ficam errados depois da importação.

## O que verificar

- Se o formato do ficheiro corresponde à ferramenta de importação.
- Se os cabeçalhos das colunas e os separadores estão corretos.
- Se o ficheiro inclui linhas duplicadas ou em branco.
- Se a conta e o intervalo de datas correspondem aos dados que queres.

## O que tentar

1. Exporta de novo o ficheiro a partir do sistema de origem, se for possível.
2. Remove linhas duplicadas e linhas vazias.
3. Verifica o mapeamento das colunas antes de confirmares a importação.
4. Experimenta um ficheiro mais pequeno para isolar o problema.

## Transações semelhantes e duplicados

O WonderMoney reconhece uma linha do ficheiro como já importada pelo identificador ou pela referência do próprio banco, quando o ficheiro os tem (um `FITID` de OFX, uma referência de CAMT.053), e, se não, por uma impressão digital construída a partir de detalhes como a data e o montante. As linhas do mesmo ficheiro que partilham esses detalhes contam em separado, por isso duas compras do mesmo montante no mesmo dia são ambas importadas. Uma linha importada antes aparece na revisão como **Já na conta** e é ignorada, a não ser que a incluas; a transação que está na conta fica como está.

Uma linha do ficheiro com o mesmo montante de uma transação que já está na conta, até 3 dias de diferença, aparece na revisão como possível duplicado, ao lado da transação com que se parece. É ignorada, a não ser que a incluas; vê [Possíveis duplicados](/pt/docs/accounts-transactions/import-transactions-csv#possíveis-duplicados).

Para saber mais sobre como as transações são associadas e guardadas, vê [Compreender transações](/pt/docs/accounts-transactions/understand-transactions).

## Quando contactar o suporte

Contacta o suporte se o ficheiro seguir o formato exigido mas as importações continuarem a falhar, ou se a importação criar transações incorretas que não consegues corrigir manualmente.
