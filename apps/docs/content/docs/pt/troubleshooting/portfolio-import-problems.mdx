## Sintomas

- Um ficheiro de portefólio não é carregado.
- As posições importadas mostram a quantidade ou o preço errados.
- As transações aparecem incompletas depois da importação.
- A importação assinala uma coluna ou um formato de data não suportados.

## O que verificar

- Se o ficheiro usa o formato esperado.
- Se a data e a moeda do portefólio estão corretas.
- Se o ficheiro inclui posições divididas ou ajustes que precisam de tratamento especial.
- Se a exportação de origem está completa.

## O que tentar

1. Exporta de novo o ficheiro a partir da plataforma de origem.
2. Confirma que as colunas correspondem ao modelo de importação.
3. Remove linhas a mais, notas ou células unidas.
4. Experimenta importar primeiro um ficheiro de amostra mais pequeno.

## Quando contactar o suporte

Contacta o suporte se o ficheiro for válido mas o portefólio continuar a ser importado com valores errados, ou se a importação falhar com dados que parecem corretos.
