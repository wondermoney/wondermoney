## Sintomas

Usa esta página quando a importação de investimentos falha ou os dados chegam incompletos.

Sinais frequentes:

- O ficheiro não é aceite
- Algumas linhas não aparecem
- Os preços ou quantidades ficam errados
- A carteira fica incompleta

## O que verificar

Confirma:

- Se o ficheiro está no formato esperado
- Se as datas estão corretas
- Se os símbolos ou ativos existem
- Se o separador decimal está consistente

## O que tentar

Tenta:

1. Abre e revê o ficheiro original.
2. Remove linhas inválidas.
3. Repete a importação com um ficheiro mais pequeno.
4. Confirma se os ativos estão mapeados corretamente.

## Quando contactar o suporte

Contacta o suporte se a importação continuar a falhar ou se existir risco de duplicação de posições.
