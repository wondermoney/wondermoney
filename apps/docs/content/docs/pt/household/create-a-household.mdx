---
title: Criar um agregado familiar
description: Sabe como um agregado familiar é criado no registo e porque não pode ser adicionado mais tarde.
---

Um agregado familiar é criado no registo, não mais tarde. Quando a primeira pessoa se regista e subscreve, a WonderMoney cria um agregado familiar à volta dessa conta e torna essa pessoa no titular.

Não é possível adicionar um agregado familiar a uma conta já existente. Se já tiver uma conta WonderMoney sem agregado familiar, o modelo de agregado não se aplica retroativamente a essa conta.

## Criar no registo

O agregado familiar faz parte do fluxo do primeiro registo. A primeira pessoa a registar-se torna-se no titular. Depois disso, o titular pode convidar outras pessoas a aderir.

Como o agregado familiar é criado no registo, a função de titular pertence sempre ao assinante original.

## A limitação apenas para novos registos

A adesão a um agregado familiar só é possível durante um novo registo. Os convites são utilizados como parte da criação de uma nova conta, pelo que não podes adicionar uma conta WonderMoney já existente a um agregado familiar.

Se uma segunda pessoa já tiver a sua própria conta, não a pode mover para o agregado familiar. Terá de completar um novo registo usando a ligação de convite.
