Esta secção tem uma página curta para cada versão da WonderMoney, escrita para quem a usa: o que há de novo, o que foi corrigido, o que um servidor próprio precisa antes de atualizar e quem contribuiu. As [versões no GitHub](https://github.com/wondermoney/wondermoney/releases) têm a lista completa de alterações e os ficheiros que o instalador descarrega.

As versões publicadas antes de esta secção existir estão descritas apenas no GitHub.

## O que cada página inclui

- **Atualizar** vem primeiro: tudo o que uma instância própria precisa, como migrações da base de dados, definições novas ou alteradas, ou um comando a correr depois de atualizar. Se usas o serviço alojado, não tens nada a fazer.
- **Novo** lista as funcionalidades e alterações que vais notar.
- **Correções** lista os problemas corrigidos.
- **Agradecimentos** nomeia todas as pessoas com um pull request na versão e assinala quem contribuiu pela primeira vez.

## Que versão tens

O menu da conta na aplicação web (ou **Mais** na aplicação móvel) mostra a versão da aplicação web e a do servidor. Para atualizar uma instância própria, segue [Atualizações e cópias de segurança](/pt/docs/self-hosting/upgrade-and-backup).
