## Descarregar e iniciar

```sh
git clone --depth 1 https://github.com/wondermoney/wondermoney.git
cd wondermoney/apps/api/deploy/selfhost
./generate-env.sh
docker compose up -d
```

O `generate-env.sh` escreve um ficheiro `.env` com segredos novos. Corre apenas uma vez: se o `.env` já existir, para sem lhe mexer, porque segredos novos terminariam as sessões existentes e tornariam ilegíveis as credenciais bancárias guardadas. Guarda o `.env` em segurança, com as tuas cópias de segurança.

No primeiro arranque, a API cria a base de dados e carrega os dados de referência (moedas, categorias e o catálogo de ativos). Isto demora um ou dois minutos. Para acompanhar:

```sh
docker compose logs -f api
```

## Criar a tua conta

Abre http://localhost:3000 e regista-te. A primeira conta numa instância nova pode sempre registar-se. Depois disso, o `SIGNUP_MODE` no `.env` decide quem mais se pode registar:

| Valor | Quem se pode registar |
|---|---|
| `open` | Qualquer pessoa que consiga aceder à aplicação web |
| `invite` | Apenas pessoas convidadas para um agregado familiar |
| `closed` | Ninguém; as contas existentes continuam a funcionar |

## Antes de configurares o email

Enquanto não houver um fornecedor de email configurado, os emails não são enviados. São escritos no registo da API, incluindo as ligações. Para recuperar uma palavra-passe ou aceitar um convite entretanto:

```sh
docker compose logs api | grep "Email not sent"
```
