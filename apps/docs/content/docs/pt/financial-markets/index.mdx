A área de Mercados Financeiros é o espaço de pesquisa de ações, ETFs e outros instrumentos cotados. Está disponível para todos os utilizadores.

Usa esta área para procurar ativos, rever os dados fundamentais nas páginas de ativos, guardar itens numa lista de acompanhamento e ler notícias de mercado.

## O que é possível fazer aqui

- Procurar um ativo pelo ticker, nome ou palavra-chave.
- Abrir a página de um ativo para rever o preço, os dados fundamentais, como o PER (preço/resultado), o EPS (lucro por ação) e o rendimento de dividendos, e a data dos próximos resultados. A data dos próximos resultados só é mostrada quando é conhecida.
- Guardar instrumentos numa lista de acompanhamento guardada na conta e sincronizada entre dispositivos.
- Ler notícias recentes dos ativos que acompanha.

## Nota sobre os dados

Os dados de mercado servem para pesquisa e acompanhamento apenas. WonderMoney não fornece aconselhamento financeiro.

Os serviços de dados de mercado têm limites de pedidos. Quando um fornecedor está indisponível, as vistas afetadas mantêm os últimos valores disponíveis em vez de falharem.

## Erros comuns

- Usar um único valor para decidir uma compra ou venda.
- Confundir listas de acompanhamento com carteiras. A lista de acompanhamento é pesquisa; uma [carteira](/pt/docs/portfolio-investments) é o registo do que possui.
- Assumir que todos os dados são atualizados exatamente ao mesmo tempo.
