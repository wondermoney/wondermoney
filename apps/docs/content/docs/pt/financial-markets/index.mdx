A área de Mercados Financeiros é o espaço de pesquisa de ações, ETFs e outros instrumentos cotados. Está disponível para todos os utilizadores.

Usa esta área para procurar ativos, rever o preço e o histórico de preços de um ativo e guardar itens numa lista de interesse.

## O que é possível fazer aqui

- Procurar um ativo pelo ticker, nome ou palavra-chave.
- Abrir a página de um ativo para rever o preço, a variação do dia e o histórico de preços.
- Guardar instrumentos numa lista de interesse guardada na conta e sincronizada entre dispositivos.

## Nota sobre os dados

Os dados de mercado servem para pesquisa e acompanhamento apenas. O WonderMoney não fornece aconselhamento financeiro.

Os dados fundamentais, os dados financeiros, os resultados e as notícias de mercado não fazem parte do plano de dados de mercado que o WonderMoney usa atualmente. Os painéis de dados fundamentais, dados financeiros e resultados na página de um ativo dizem-no; os preços, o histórico de preços e o perfil da empresa não são afetados.

Quando não há cotação em tempo real para um ativo, a página mostra o último fecho e a respetiva data.

Os serviços de dados de mercado têm limites de pedidos. Quando um fornecedor está indisponível, as vistas afetadas mantêm os últimos valores disponíveis em vez de falharem.

## Erros comuns

- Usar um único valor para decidir uma compra ou venda.
- Confundir listas de interesse com portefólios. A lista de interesse é pesquisa; um [portefólio](/pt/docs/portfolio-investments) é o registo do que possuis.
- Assumir que todos os dados são atualizados exatamente ao mesmo tempo.
