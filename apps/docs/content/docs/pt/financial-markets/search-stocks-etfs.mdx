## Como funciona a pesquisa

- A pesquisa encontra correspondências por ticker, nome do ativo ou palavra-chave.
- A listagem principal para o termo aparece em primeiro lugar nos resultados.
- Os resultados são renovados enquanto escreve. O campo espera um breve intervalo depois de parar de escrever antes de obter novos resultados.

## Comportamento da pesquisa

- Usa o teclado para percorrer os resultados e prime Enter para selecionar um.
- Ao focar o campo de pesquisa, o texto existente fica selecionado, para poderes começar a escrever e substituí-lo diretamente, sem teres de o apagar à mão.
- Um campo vazio é seguro: não mostra resultados nem gera erro. Escreve alguns caracteres para ver correspondências.

## Dicas de pesquisa

- Procura primeiro pelo ticker, se o souberes.
- Experimenta o nome do ativo se o ticker não for óbvio.
- Usa palavras-chave amplas quando estiveres a explorar um mercado ou setor.

## Para que servem os resultados

- Abrir a página de detalhe do ativo.
- Adicionar um ativo à lista de acompanhamento.
- Confirmar dados de mercado antes de importar para uma carteira.

## Erros comuns

- Escolher a classe de ações ou a bolsa errada.
- Assumir que nomes parecidos significam ativos iguais.
- Usar os resultados da pesquisa como sinal de compra ou venda.
