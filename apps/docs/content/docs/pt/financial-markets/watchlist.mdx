A lista de interesse é uma lista guardada de ativos para acompanhar sem os adicionar ainda a um portefólio.

Ajuda a separar a pesquisa das posições detidas.

## Guardada na conta

A lista de interesse é guardada na tua conta WonderMoney, não no navegador. Isto significa que a lista é a mesma onde quer que inicies sessão: adiciona um item no telemóvel e ele aparece na versão web, e o contrário também se aplica.

Como a lista está ligada à conta, não se perde quando mudas de dispositivo ou navegador, nem quando limpas os dados do navegador.

## O que significa o valor de variação

A lista mostra um valor de variação para cada ativo. Trata-se da variação diária — a diferença entre o preço mais recente e o fecho do dia anterior. Não é um preço em tempo real nem em streaming. O valor é atualizado quando os dados de mercado são renovados, não de forma contínua.

## Para que serve

- Seguir instrumentos que podem ser analisados mais tarde.
- Acompanhar uma lista curta de ativos em diferentes mercados.
- Manter separada a pesquisa das posições detidas.

## O que esperar

- Os ativos guardados ficam no mesmo sítio, em todos os dispositivos.
- É possível abrir cada ativo na lista para rever os detalhes.
- A lista de interesse não altera o desempenho nem as posições do portefólio.

## Erros comuns

- Adicionar todos os ativos interessantes e perder o foco.
- Usar a lista de interesse como registo do que já possuis.
- Esperar que os itens da lista de interesse afetem os totais do portefólio.
- Interpretar a variação diária como um preço em tempo real.
