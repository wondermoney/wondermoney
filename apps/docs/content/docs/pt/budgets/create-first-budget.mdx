---
title: Criar o teu primeiro orçamento
description: Define um orçamento do agregado com categorias e valores mensais.
---

O assistente de orçamento ajuda a escolher a configuração do agregado, as categorias relevantes e os objetivos mensais. Começa com um orçamento simples, alinhado com a forma como realmente gastas.

## Começa com envelopes, não com a perfeição

Pensa em cada categoria como um envelope com um valor mensal. A primeira versão só precisa de ser realista o suficiente para orientar decisões, não perfeita logo no primeiro dia.

## Antes de começar

Tem em mente as principais despesas do agregado e um mês recente de gastos. Podes afinar o orçamento mais tarde, por isso a primeira versão só precisa das categorias que uses agora.

## Passos

1. Abre o assistente de orçamento.
2. Confirma o tamanho do agregado e os dados das pessoas a cargo.
3. Escolhe as categorias que queres acompanhar.
4. Define um valor mensal para cada categoria.

## Rever

Depois de guardar o orçamento, compara os totais mensais com os gastos reais. Se uma categoria parecer demasiado ampla ou demasiado estreita, ajusta-a antes de confiar nos números.

## Problemas comuns

- Demasiadas categorias tornam o orçamento difícil de manter.
- Os dados do agregado não correspondem às pessoas que partilham despesas.
- Os valores mensais foram introduzidos por engano como totais anuais.
- Foi adicionada uma categoria que raramente aparece nos gastos.
