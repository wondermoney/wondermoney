A documentação da WonderMoney é o centro de ajuda para quem usa o produto no dia a dia. Começa pela secção que corresponde à tua tarefa e segue os guias ligados por ordem.

## O que esta ajuda cobre

- Começar: criar conta, escolher o país, ligar um banco ou adicionar uma conta offline, iniciar sessão, recuperar acesso, ativar MFA e ler o painel.
- Contas e transações: ligações bancárias, contas manuais, revisão de transações, categorização, pagamentos recorrentes e importação CSV.
- Orçamentos: criar o primeiro orçamento, escolher categorias e acompanhar a despesa mensal.

## Caminho de configuração recomendado

1. [Cria uma conta](/pt/docs/start-here/create-account) e escolhe o teu país.
2. No passo da conta, [liga um banco diretamente](/pt/docs/start-here/connect-first-bank-account) ou [adiciona uma conta offline](/pt/docs/accounts-transactions/manual-offline-account).
3. [Compreender transações](/pt/docs/accounts-transactions/understand-transactions) para que a despesa seja categorizada corretamente.
4. [Cria o teu primeiro orçamento](/pt/docs/budgets/create-first-budget) usando o [método dos envelopes](/pt/docs/budgets/envelope-method).
5. [Cria uma carteira](/pt/docs/portfolio-investments/create-portfolio) se quiseres incluir investimentos no património líquido.

Usa as páginas de resolução de problemas quando um fluxo parar a meio ou quando os dados importados não corresponderem ao esperado.

A WonderMoney usa o mesmo modelo base em toda a aplicação: inicia sessão para acederes à tua conta, liga contas bancárias para trazeres transações e constrói orçamentos e a vista da carteira a partir dos teus dados ligados. Chegar ao passo final do primeiro arranque marca o primeiro uso como completo, para que o painel abra normalmente no próximo início de sessão.
