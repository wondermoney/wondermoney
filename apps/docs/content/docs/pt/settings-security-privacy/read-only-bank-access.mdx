---
title: Acesso bancário só de leitura
description: Compreende que dados bancários a WonderMoney pode ler e o que não pode alterar.
---

A WonderMoney pode ler os dados bancários ligados para mostrar saldos, transações e atividade da conta.

Usa este acesso quando quiseres dados da conta na WonderMoney sem dar à aplicação permissão para movimentar dinheiro ou editar registos bancários.

## O que significa só de leitura

O acesso só de leitura permite à aplicação obter dados da tua ligação bancária. Não permite à WonderMoney movimentar dinheiro nem alterar registos no teu banco.

## Porque é importante

- Suporta a importação de transações.
- Suporta as vistas de conta e de fluxo de caixa.
- Ajuda a manter os teus dados financeiros atualizados.

Se uma ligação bancária deixar de atualizar, verifica primeiro o estado da ligação bancária e depois revê os passos de resolução de problemas desse fornecedor.
