O WonderMoney pede o teu consentimento antes de ativar o assistente, e podes alterá-lo em qualquer altura a partir das definições. A análise não é uma definição da conta: o site wonder.money pergunta por ela numa faixa, e as aplicações seguem o que o servidor está configurado para fazer.

## Como é recolhido o consentimento

Criar uma conta significa aceitar os Termos de serviço e a Política de privacidade: a página de registo na web di-lo por baixo do formulário, e a aplicação móvel tem uma caixa para assinalares. O registo não pergunta pela análise.

O assistente de IA tem o seu próprio consentimento: fica desligado até selecionares **Ativar assistente** no ecrã de consentimento, e essa escolha é guardada com a tua conta, pelo que se aplica onde quer que inicies sessão.

A análise e a medição de publicidade são perguntadas no site wonder.money, não na aplicação. Na primeira visita, a faixa **Escolhas de privacidade** oferece **Usar apenas o necessário**, **Personalizar** e **Permitir tudo**; **Análise** e **Publicidade** ficam desligadas a menos que as permitas. A escolha é guardada nesse navegador, não na tua conta, por isso cada navegador pergunta uma vez. Para a alterares, seleciona o botão **Escolhas de privacidade** no canto de qualquer página do site.

As aplicações web e móvel não têm uma opção de análise por conta. A aplicação web só carrega análise num servidor cujo operador a tenha configurado, e um servidor auto-alojado não tem nenhuma por omissão (vê [Analytics](/pt/docs/self-hosting/configure#analytics)). A aplicação móvel só envia eventos de utilização enquanto está ligada ao servidor para o qual foi compilada.

## O que podes controlar

- Se as funcionalidades do assistente estão ativas para a conta.
- Se o lançador do assistente está visível.
- Se o site wonder.money pode usar análise e medição de publicidade no teu navegador.

## Como alterar a decisão

1. Abre **Definições** e escolhe **Assistente**.
2. Liga ou desliga **Assistente ativo**. Liga **Ocultar lançador** para manteres o assistente disponível sem o lançador.

A alteração é guardada assim que a fazes. Para desligar todas as funcionalidades de IA de uma vez, usa **Definições > Privacidade > Ocultar funcionalidades de IA**.

Se uma alteração não parecer aplicada, termina a sessão, volta a entrar e verifica novamente as definições.

## O que o consentimento não permite

O consentimento para as funcionalidades do assistente não autoriza o WonderMoney a movimentar dinheiro, iniciar transações ou alterar registos bancários. O assistente só pode ler os dados expostos às funcionalidades do assistente.
