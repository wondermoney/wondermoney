## O que esta secção abrange

- Preferências de perfil e aparência
- Preferências de email
- Alterações de palavra-passe
- Autenticação de dois fatores
- Consentimento e definições do assistente
- Privacidade dos dados e eliminação da conta
- Acesso bancário e serviços ligados

## Para onde ir

- Usa **Segurança** para alterações de palavra-passe e de 2FA.
- Usa **Preferências de email** para controlar as categorias de email que recebes e para as desligar todas de uma vez.
- Usa **Assistente** para o consentimento do assistente, a visibilidade do launcher e os controlos do registo de auditoria.
- Usa **Privacidade dos dados** para definições de privacidade da conta e escolhas de consentimento.
- Usa **Acesso bancário só de leitura** para perceber que dados bancários a aplicação pode ler.
