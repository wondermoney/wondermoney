---
title: Chaves de acesso
description: Inicia sessão com a impressão digital, o rosto ou o PIN do dispositivo em vez de escreveres o email e a palavra-passe.
---

Uma chave de acesso (passkey) permite-te iniciar sessão sem escreveres o email nem a palavra-passe. O teu dispositivo guarda a chave de acesso, e desbloqueia-la com a impressão digital, o rosto ou o PIN do dispositivo, um telemóvel ou uma chave de segurança.

As chaves de acesso são uma forma extra de iniciar sessão. A palavra-passe e o início de sessão com Google e com Apple continuam a funcionar, e manténs a tua palavra-passe. Não é possível criar uma conta só com uma chave de acesso.

As chaves de acesso funcionam na aplicação web e, na aplicação móvel, no servidor para o qual a aplicação foi compilada (consulta [Chaves de acesso na aplicação móvel](#chaves-de-acesso-na-aplicação-móvel)).

## Adicionar uma chave de acesso

1. Abre **Definições → Segurança** e encontra a secção **Chaves de acesso**.
2. Seleciona **Adicionar uma chave de acesso**.
3. Segue o pedido do navegador. Pode pedir a impressão digital, o rosto, o PIN do dispositivo, um telemóvel ou uma chave de segurança.

Adicionar uma chave de acesso exige um início de sessão recente. Se iniciaste sessão há mais de um dia, a aplicação pede-te que inicies sessão outra vez primeiro.

Depois de iniciares sessão com a palavra-passe, a aplicação oferece uma vez adicionar uma chave de acesso, se o navegador suportar chaves de acesso e ainda não tiveres nenhuma. Seleciona **Agora não** para a dispensar; esse navegador não volta a perguntar.

## Iniciar sessão com uma chave de acesso

Na página de início de sessão, seleciona **Iniciar sessão com uma chave de acesso**. Nos navegadores que suportam o preenchimento automático de chaves de acesso, também podes escolher uma chave guardada nas sugestões do campo de email.

Não há email nem palavra-passe para escrever.

## Chaves de acesso e autenticação de dois fatores

Um início de sessão com chave de acesso não pede o código do autenticador. Uma chave de acesso já prova duas coisas: tens o dispositivo, e desbloqueaste-o com a impressão digital, o rosto ou o PIN.

Iniciar sessão com a palavra-passe continua a pedir o código quando a autenticação de dois fatores está ativa.

## Gerir as tuas chaves de acesso

Cada chave de acesso em **Definições → Segurança → Chaves de acesso** mostra o nome, quando foi adicionada (**Adicionada** e uma data) e quando foi usada pela última vez (**Usada pela última vez** e uma data, ou **Nunca usada**).

Uma chave de acesso nova recebe o nome do gestor de palavras-passe que a guarda quando o navegador o indica, como "Google Password Manager", "Windows Hello" ou "1Password". Caso contrário, chama-se "Passkey". Seleciona **Mudar o nome** para dares a cada chave de acesso um nome que as distinga.

Seleciona **Eliminar** para remover uma chave de acesso. Deixa de funcionar no WonderMoney de imediato, mas continua no teu gestor de palavras-passe ou no teu dispositivo até a removeres também aí.

Os tokens de API pessoais não podem listar, adicionar nem remover chaves de acesso.


## Chaves de acesso na aplicação móvel

As chaves de acesso fazem parte da aplicação móvel a partir da versão 1.0.3. Uma versão anterior não mostra **Iniciar sessão com uma chave de acesso**: atualiza a aplicação e, até lá, inicia sessão com a palavra-passe, a Google ou a Apple. A aplicação mostra a sua versão no ecrã **Mais**.

No ecrã de início de sessão da aplicação para iOS e Android, toca em **Iniciar sessão com uma chave de acesso** e desbloqueia a chave com a impressão digital, o rosto ou o PIN do dispositivo. Uma chave de acesso que adicionaste na web funciona na aplicação quando o telemóvel a tem, por exemplo através do Porta-chaves iCloud ou do Gestor de palavras-passe da Google, e uma adicionada na aplicação funciona na web.

Na aplicação, **Definições → Segurança → Chaves de acesso** lista as tuas chaves de acesso. Toca em **Adicionar uma chave de acesso** para criar uma no telemóvel, ou em **Eliminar** para remover uma. Para mudar o nome, usa a aplicação web.

A aplicação só oferece chaves de acesso no servidor para o qual foi compilada: a aplicação publicada, no wonder.money. Ligada a um servidor alojado por ti, a aplicação oculta **Iniciar sessão com uma chave de acesso** e **Adicionar uma chave de acesso**, e inicias sessão com a palavra-passe, a Google, a Apple ou o início de sessão único. [Usar a aplicação móvel com o teu servidor](/pt/docs/self-hosting/mobile-app) explica porquê.
