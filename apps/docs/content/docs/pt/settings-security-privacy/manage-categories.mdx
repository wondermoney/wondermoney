---
title: Gerir categorias
description: Cria, edita, funde e revê categorias usadas na aplicação WonderMoney.
---

As categorias ajudam a organizar transações e orçamentos. Usa esta página para perceber como as alterações afetam os dados já existentes.

## O que podes gerir

- Criar uma nova categoria para um tipo recorrente de despesa ou rendimento.
- Renomear uma categoria sem mudar a sua finalidade.
- Ocultar ou arquivar categorias que já não quer usar.
- Rever onde uma categoria já está a ser usada antes de fazer alterações maiores.

## Como funcionam as alterações

As alterações às categorias costumam afetar primeiro os itens futuros. As transações antigas podem manter a categoria atual até serem atualizadas manualmente. Se renomeares uma categoria, o novo nome aparece onde essa categoria for apresentada. Se fundires ou substituíres uma categoria, confirma se os orçamentos e resumos continuam a refletir o grupo correto.

## Antes de editar

- Confirma que estás na conta certa.
- Verifica se a categoria já está ligada a orçamentos ou transações importadas.
- Decide se queres renomear, ocultar ou substituir a categoria.

## O que fazer

1. Abre as definições de categorias.
2. Seleciona a categoria que queres alterar.
3. Aplica a edição e revê a pré-visualização, se existir.
4. Guarda e confirma a categoria numa transação ou orçamento.

## Erros comuns

- Criar categorias duplicadas com nomes quase iguais.
- Ocultar uma categoria que ainda aparece em resumos.
- Renomear uma categoria sem verificar os dados importados.
