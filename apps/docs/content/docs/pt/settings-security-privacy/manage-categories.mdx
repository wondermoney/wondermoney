---
title: Gerir categorias
description: Cria, edita, funde e revê categorias usadas na aplicação WonderMoney.
---

As categorias ajudam a organizar transações e orçamentos. Usa esta página para perceber como as alterações afetam os dados já existentes.

## O que podes gerir

- Criar uma categoria tua com **Adicionar Categoria**: um nome, uma cor, um ícone e, se quiseres, uma categoria principal.
- Editar uma categoria tua: o nome, a cor, o ícone e a categoria principal.
- Eliminar uma categoria tua.
- Escolher se uma categoria **Conta como despesa**. Desligado, os movimentos da categoria ficam fora das despesas nos relatórios, nos orçamentos e no fluxo de caixa da página inicial.

As categorias do sistema não podem ser editadas nem eliminadas. Podes, ainda assim, escolher se contam como despesa.

## Como funcionam as alterações

As alterações às categorias costumam afetar primeiro os itens futuros. As transações antigas podem manter a categoria atual até serem atualizadas manualmente. Se renomeares uma categoria, o novo nome aparece onde essa categoria for apresentada. O formulário avisa-te quando um nome ou uma cor já estão em uso.

## Antes de editar

- Confirma que estás na conta certa.
- Verifica se a categoria já está ligada a orçamentos ou transações importadas.
- Decide se queres renomear ou eliminar a categoria.

## O que fazer

1. Abre **Definições** e escolhe **Categorias**. Na aplicação móvel, abre **Mais > Definições** e escolhe **Categorias**.
2. Seleciona **Adicionar Categoria**, ou a ação de editar ao lado da categoria que queres alterar.
3. Aplica a edição e guarda-a.
4. Confirma a categoria numa transação ou orçamento.

## Erros comuns

- Criar categorias duplicadas com nomes quase iguais.
- Eliminar uma categoria que ainda é usada em orçamentos ou resumos.
- Renomear uma categoria sem verificar os dados importados.
