---
title: Importar carteira por CSV
description: Importa posições e transações de carteira a partir de um ficheiro CSV.
---

A importação CSV é a forma mais rápida de carregar dados do corretor para o WonderMoney.

## O que é possível importar

- Posições
- Transações
- Posições atuais, quando o export as incluir

## Como importar

1. Exporta os dados do corretor.
2. Abre a carteira que deve ser atualizada.
3. Carrega o ficheiro CSV.
4. Aguarda o processamento da importação.
5. Corrige mapeamentos ou linhas não resolvidas, se forem reportados.

## Melhores resultados

- Usa uma exportação recente do corretor.
- Mantém uma carteira por conta de corretor, quando possível.
- Revê tickers, quantidades, datas e moedas no export do corretor antes de carregar.
- Se algumas linhas precisarem de resolução de ativos, segue as instruções apresentadas após a importação.

## Comportamento atual

A WonderMoney processa os ficheiros CSV carregados após o upload. Não existe uma revisão de linhas antes de guardar.

## Erros comuns

- Carregar o tipo de ficheiro errado.
- Importar linhas duplicadas de um export antigo.
- Deixar a coluna da moeda vazia quando o export inclui várias moedas.
- Assumir que todos os corretores usam os mesmos nomes de colunas.
