Cria uma carteira quando for necessário agrupar posições, transações e desempenho num só espaço.

## Quando criar uma

- Usas mais do que um corretor ou conta.
- É necessário separar investimento de longo prazo de outras posições.
- São geridas estratégias diferentes e são necessárias vistas de desempenho separadas.

## Como criar

1. Abre Investimentos de carteira.
2. Escolhe Criar carteira.
3. Introduz um nome que corresponda à conta ou estratégia.
4. Escolhe a moeda usada pela carteira.
5. Guarda e depois adiciona posições ou importa transações.

## Bons padrões de nome

- Nome do corretor mais o tipo de conta, como `DEGIRO Long Term`.
- Nome da estratégia, como `ETF Core`.
- Um propósito claro, como `Reforma` ou `Poupança dos filhos`.

## Erros comuns

- Reutilizar a mesma carteira para objetivos sem relação.
- Escolher a moeda errada.
- Esperar até a carteira estar completa para começar. É possível criá-la primeiro e preenchê-la depois.
