---
title: Criar um portefólio
description: Cria um novo portefólio de investimento na aplicação WonderMoney.
---

Cria um portefólio quando for necessário agrupar posições, transações e desempenho num só espaço.

## Quando criar uma

- Usas mais do que um corretor ou conta.
- É necessário separar investimento de longo prazo de outras posições.
- São geridas estratégias diferentes e são necessárias vistas de desempenho separadas.

## Como criar

1. Abre Portefólio, em Investimentos, na barra lateral.
2. Escolhe Criar portefólio.
3. Introduz um nome que corresponda à conta ou estratégia.
4. Escolhe a moeda usada pelo portefólio.
5. Escolhe Criar e depois adiciona posições ou importa transações.

## Bons padrões de nome

- Nome do corretor mais o tipo de conta, como `DEGIRO Long Term`.
- Nome da estratégia, como `ETF Core`.
- Um propósito claro, como `Reforma` ou `Poupança dos filhos`.

## Erros comuns

- Reutilizar o mesmo portefólio para objetivos sem relação.
- Escolher a moeda errada.
- Esperar até o portefólio estar completo para começar. É possível criá-lo primeiro e preenchê-lo depois.
