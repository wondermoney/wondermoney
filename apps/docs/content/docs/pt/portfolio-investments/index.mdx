Os investimentos de carteira reúnem as posições, transações e desempenho num só local.

Usa esta secção para criar carteiras, adicionar transações, importar ficheiros CSV e rever alocação e desempenho.

## O que é possível fazer aqui

- Criar uma ou mais carteiras para corretores, contas ou estratégias diferentes.
- Adicionar compras, vendas, dividendos, comissões e outras transações.
- Importar posições e transações de um CSV do corretor.
- Rever a alocação por ativo e comparar o desempenho com um benchmark.

## Como funciona

Os dados de carteira na aplicação WonderMoney são importados manualmente. A maioria dos corretores europeus não disponibiliza APIs úteis, por isso a entrada é feita por CSV ou por transações manuais.

Depois de as posições estarem na aplicação, os preços são atualizados diariamente e o valor da carteira é atualizado automaticamente.

## Antes de começar

- Confirma que o ficheiro exportado pelo corretor inclui as colunas necessárias.
- Usa a mesma moeda da carteira sempre que possível.
- Se geres várias estratégias, cria uma carteira separada para cada uma.

## Erros comuns

- Misturar posições de contas diferentes na mesma carteira.
- Importar o mesmo CSV duas vezes.
- Esperar que o valor da carteira coincida com o saldo do corretor antes de importar todas as transações.
- Usar estas páginas como conselho financeiro. Mostram dados apenas.
