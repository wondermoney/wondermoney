---
title: Resolver problemas de importação de carteira
description: Corrige problemas comuns de importação de carteira por CSV.
---

Se uma importação falhar ou os números não parecerem corretos, segue as verificações abaixo.

## Problemas comuns

- O ficheiro não é um CSV exportado pelo corretor.
- Faltam colunas obrigatórias.
- Tickers ou identificadores não correspondem à lista de ativos.
- As mesmas linhas já foram importadas antes.
- Os separadores de moeda ou decimais não coincidem com o formato do ficheiro.

## O que fazer

1. Exporta novamente o ficheiro do corretor.
2. Confirma que a importação é efetuada para a carteira correta.
3. Verifica a pré-visualização para duplicados ou valores em falta.
4. Corrige o ficheiro de origem se datas, quantidades ou moedas estiverem erradas.
5. Repete a importação apenas quando a pré-visualização parecer correta.

## Quando contactar o apoio

Contacta o apoio se o ficheiro for válido mas o importador continuar a rejeitá-lo, ou se as linhas forem importadas com sucesso mas as posições resultantes estiverem claramente erradas.
