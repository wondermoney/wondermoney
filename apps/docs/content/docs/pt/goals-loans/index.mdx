Os objetivos e empréstimos ajudam a acompanhar dinheiro com um propósito específico ou uma responsabilidade específica.

Usa esta secção para criar objetivos, planear a amortização de dívidas, registar empréstimos ou crédito, ligar contas como contexto e seguir reembolsos.

## O que é possível fazer aqui

- Criar um objetivo de poupança para dinheiro que deve ser reservado, ou um objetivo de amortização de dívida para passivos que devem ser pagos.
- Ordenar os objetivos por prioridade nas listas.
- Rever objetivos arquivados e restaurá-los quando for necessário.
- Adicionar um empréstimo ou linha de crédito para passivos que devem ser acompanhados.
- Ligar um objetivo a uma conta como contexto.
- Atribuir dinheiro a um objetivo dentro do limite de disponível para atribuir do orçamento.
- Registar reembolsos de um empréstimo.

## Como funciona

Os objetivos são reservas apoiadas pelo orçamento. Acompanham para que serve o dinheiro, não onde ele está guardado. A atribuição de dinheiro a um objetivo está limitada ao que está disponível no [orçamento](/pt/docs/budgets/); o limite de disponível para atribuir mostra esse valor antes de atribuir. Os empréstimos ajudam a monitorizar o que é devido e como os reembolsos alteram o saldo ao longo do tempo.

Para definições simples de termos de orçamento, consulta o [glossário](/pt/docs/glossary).

## Erros comuns

- Esperar que uma ligação a uma conta mova dinheiro automaticamente.
- Tratar ligações a contas como saldo oficial ou registo bancário.
- Misturar o progresso de um objetivo com saldos bancários.
- Usar este módulo para planear rentabilidade dos investimentos. É para objetivos e passivos, não para projeções.
