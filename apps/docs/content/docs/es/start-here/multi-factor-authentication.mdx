---
title: Autenticación de dos factores
description: Configura y usa la autenticación de dos factores para iniciar sesión.
---

La autenticación de dos factores añade una segunda comprobación al iniciar sesión. Cuando está activada, confirmas tu identidad con un código u otro método aprobado antes de que se abra la sesión.

## Antes de empezar

Mantén el acceso al teléfono, a la aplicación de autenticación o al método de recuperación vinculado a la cuenta. Si vas a cambiar de dispositivo, asegúrate de que el método antiguo siga funcionando hasta que el nuevo esté listo.

## Pasos

1. Inicia sesión con tu correo electrónico y tu contraseña.
2. Introduce el código de verificación o aprueba el aviso.
3. Guarda los códigos de recuperación si te los proporcionan.
4. Confirma que la sesión se abre con normalidad.

## Revisa tu configuración

Prueba el flujo de inicio de sesión una vez después de la configuración para saber que el segundo factor funciona antes de necesitarlo. Si dependes de los códigos de recuperación, guárdalos en un lugar seguro distinto del dispositivo que usas a diario.

## Problemas comunes

- El código caducó antes de introducirlo.
- La aplicación de autenticación está en un dispositivo reemplazado o restablecido.
- Los códigos de recuperación se agotaron o se guardaron en el lugar equivocado.
- El navegador pide un nuevo desafío después de cerrar la sesión.
