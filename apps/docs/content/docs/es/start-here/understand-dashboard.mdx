El panel reúne los saldos, la actividad reciente y los accesos directos en una sola vista. Úsalo para confirmar que tus cuentas están conectadas y para llegar rápido a las transacciones o los presupuestos.

## Antes de empezar

Asegúrate de que exista al menos una cuenta o un presupuesto para que el panel tenga datos reales que mostrar. Las cuentas nuevas pueden mostrar estados vacíos hasta que termine la primera sincronización. Completar la incorporación marca tu primer uso como completado, de modo que el panel se muestra con normalidad en el siguiente inicio de sesión.
Si todavía estás aprendiendo los términos de esta página, consulta el [glosario](/es/docs/glossary).

## Secciones principales

- Resumen de saldo para la posición general.
- Tarjetas de cuenta para las cuentas bancarias y manuales individuales.
- Transacciones recientes para la actividad más reciente.
- Accesos directos para presupuestos y gestión de cuentas.
- Navegación lateral para cuentas, presupuestos, cartera y configuración.

## Cómo usarlo

Comprueba primero los saldos y después revisa las últimas transacciones por si hay algo inesperado. Usa los accesos directos para ir a la zona que necesita atención, como una importación que falta o una categoría sin asignar.

## Problemas comunes

- Los saldos están desactualizados porque una conexión todavía no se ha sincronizado.
- Una cuenta nueva sigue vacía después del registro.
- La actividad reciente no incluye una cuenta manual hasta que añades entradas.
