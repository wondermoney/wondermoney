La documentación de WonderMoney es el centro de ayuda al cliente para el uso diario del producto. Empieza por la sección que coincida con tu tarea y sigue después las guías enlazadas en orden.

## Qué cubre este centro de ayuda

- Empezar por aquí: crea una cuenta, elige tu país, conecta un banco o añade una cuenta manual, inicia sesión, recupera el acceso, configura el MFA y consulta el panel.
- Cuentas y transacciones: conexiones bancarias, cuentas manuales, revisión de transacciones, categorización, pagos recurrentes e importaciones CSV.
- Presupuestos: crea un primer presupuesto, elige categorías y haz un seguimiento del gasto mensual.

## Ruta de configuración recomendada

1. [Crea una cuenta](/es/docs/start-here/create-account) y elige tu país.
2. En el paso de la cuenta, [conecta un banco directamente](/es/docs/start-here/connect-first-bank-account) o [añade una cuenta manual](/es/docs/accounts-transactions/manual-offline-account).
3. [Entender las transacciones](/es/docs/accounts-transactions/understand-transactions) para que los gastos se categoricen correctamente.
4. [Crea tu primer presupuesto](/es/docs/budgets/create-first-budget) con el [método de sobres](/es/docs/budgets/envelope-method).
5. [Crea una cartera](/es/docs/portfolio-investments/create-portfolio) si quieres que las inversiones cuenten en el patrimonio neto.

Usa las páginas de resolución de problemas cuando un flujo se interrumpa a mitad de camino o cuando los datos importados no coincidan con lo que esperabas.

WonderMoney usa el mismo modelo central en toda la aplicación: inicia sesión para acceder a tu cuenta, conecta cuentas bancarias para traer transacciones y crea presupuestos y vistas de cartera a partir de tus datos vinculados. Llegar al último paso de la incorporación marca tu primer uso como completado, de modo que el panel se muestra con normalidad en el siguiente inicio de sesión.
