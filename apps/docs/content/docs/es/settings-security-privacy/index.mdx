## Qué cubre esta sección

- Preferencias de perfil y apariencia
- Preferencias de correo
- Cambios de contraseña
- Autenticación de dos factores
- Consentimiento del asistente y configuración
- Privacidad de los datos y eliminación de la cuenta
- Acceso bancario y servicios conectados

## A dónde ir

- Usa **Seguridad** para los cambios de contraseña, de autenticación de dos factores y de llaves de acceso.
- Usa **Notificaciones** para controlar qué categorías de correo recibes y para desactivarlas todas a la vez.
- Usa **Asistente** para el consentimiento del asistente, la visibilidad del lanzador, los cambios pendientes y el registro de auditoría.
- Usa **Privacidad** para ocultar las funciones de IA, exportar o restaurar tus datos y eliminar tu cuenta.
- Usa **Conexiones** para revisar el acceso bancario de solo lectura vinculado a tu cuenta.
