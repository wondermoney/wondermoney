WonderMoney pide tu consentimiento antes de activar el asistente, y puedes cambiarlo en cualquier momento desde la configuración. La analítica del navegador tiene un consentimiento separado, guardado en este navegador y modificable en **Ajustes → Privacidad**.

## Cómo se recopila el consentimiento

Crear una cuenta significa aceptar los Términos del servicio y la Política de privacidad: la página de registro en la web lo indica bajo el formulario, y la aplicación móvil tiene una casilla que debes marcar. El consentimiento para analítica es independiente de la creación de la cuenta.

El asistente de IA tiene su propio consentimiento: permanece desactivado hasta que seleccionas **Activar asistente** en su pantalla de consentimiento, y esa elección se guarda con tu cuenta, así que se aplica dondequiera que inicies sesión.

El sitio web wonder.money pide por separado consentimiento para analítica y medición de publicidad. En tu primera visita, el aviso **Opciones de privacidad** ofrece **Usar solo lo necesario**, **Personalizar** y **Permitir todo**; **Análisis** y **Publicidad** permanecen desactivados salvo que los permitas. La elección se guarda en ese navegador, no en tu cuenta, así que cada navegador pregunta una vez. Para cambiarla, selecciona el botón **Opciones de privacidad** en la esquina de cualquier página del sitio.

La aplicación web solo carga analítica del navegador cuando el operador la configura y tú la permites. Puedes retirar ese consentimiento en **Ajustes → Privacidad**. Un servidor autoalojado no tiene analítica del navegador de forma predeterminada (consulta [Analítica](/es/docs/self-hosting/configure#analítica)). Esta elección no cambia los eventos de la API y del worker ni la telemetría móvil, configurados por separado. La aplicación móvil solo envía eventos de uso mientras está conectada al servidor para el que se compiló.

## Qué puedes controlar

- Si las funciones del asistente están activadas para tu cuenta.
- Si el lanzador del asistente es visible.
- Si la aplicación web puede usar analítica en este navegador.
- Si el sitio web wonder.money puede usar análisis y medición de publicidad en tu navegador.

## Cómo cambiar tu decisión

1. Abre **Configuración** y elige **Asistente**.
2. Activa o desactiva **Asistente activado**. Activa **Ocultar lanzador** para mantener el asistente disponible sin su lanzador.

El cambio se guarda en cuanto lo haces. Para desactivar todas las funciones de IA a la vez, usa **Configuración > Privacidad > Ocultar funciones de IA**.

Si un cambio no parece aplicarse, cierra la sesión y vuelve a iniciarla, y luego revisa la configuración de nuevo.

## Qué no permite el consentimiento

El consentimiento de las funciones del asistente no permite a WonderMoney mover dinero, iniciar transacciones ni cambiar registros bancarios. El asistente solo puede leer los datos expuestos a las funciones del asistente.
