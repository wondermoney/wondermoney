---
title: Gestionar categorías
description: Crea, edita, fusiona y revisa las categorías que se usan en WonderMoney.
---

Las categorías mantienen organizadas las transacciones y los presupuestos. Usa esta página para entender cómo afectan los cambios de categoría a los datos existentes.

## Qué puedes gestionar

- Crear una categoría nueva para un tipo de gasto o ingreso recurrente.
- Cambiar el nombre de una categoría sin cambiar su finalidad.
- Ocultar o archivar las categorías que ya no quieres usar.
- Revisar dónde se usa ya una categoría antes de hacer cambios importantes.

## Cómo funcionan los cambios de categoría

Los cambios de categoría suelen afectar primero a los elementos futuros. Las transacciones existentes pueden conservar su categoría actual a menos que las actualices manualmente. Si cambias el nombre de una categoría, el nombre nuevo aparece dondequiera que se muestre esa categoría. Si fusionas o sustituyes una categoría, comprueba que los presupuestos y los resúmenes sigan reflejando el grupo correcto.

## Antes de editar categorías

- Confirma que estás en la cuenta correcta.
- Comprueba si la categoría ya está asociada a presupuestos o a transacciones importadas.
- Decide si quieres cambiar el nombre, ocultar o sustituir la categoría.

## Qué hacer

1. Abre la configuración de categorías.
2. Selecciona la categoría que quieres cambiar.
3. Aplica la edición y revisa la vista previa, si se muestra.
4. Guarda y verifica la categoría en una pantalla de transacciones o de presupuestos.

## Errores comunes

- Crear categorías duplicadas con nombres ligeramente diferentes.
- Ocultar una categoría que todavía se usa en los resúmenes.
- Cambiar el nombre de una categoría sin revisar los datos importados.
