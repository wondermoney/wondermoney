---
title: Autenticación de dos factores
description: Añade un segundo paso al inicio de sesión con una aplicación de autenticación.
---

La autenticación de dos factores añade otra verificación cuando inicias sesión.

Es especialmente útil cuando quieres una protección extra además de tu contraseña.

## Activarla

En la web:

1. Abre **Configuración**, elige **Seguridad** y busca **Autenticación de dos factores**.
2. Selecciona **Activar 2FA** e introduce la contraseña de tu cuenta.
3. Escanea el código QR con una aplicación de autenticación. Guarda en un lugar seguro los códigos de respaldo que aparecen debajo; **Copiar códigos** los copia. Cada uno se puede usar una vez si pierdes el acceso a tu aplicación de autenticación.
4. Selecciona **Continuar**, introduce el código de 6 dígitos que muestra la aplicación y selecciona **Enviar**.

En la aplicación móvil, abre **Más > Configuración > Seguridad** y selecciona **Activar la autenticación de dos factores**. Añade la clave de configuración a tu aplicación de autenticación, introduce el código de 6 dígitos que muestra y selecciona **Confirmar código**.

## Desactivarla

En la web, selecciona **Desactivar 2FA** en la misma sección e introduce la contraseña de tu cuenta. En la aplicación móvil, selecciona **Desactivar la autenticación de dos factores**.

## Problemas habituales

- El código ha caducado.
- La aplicación de autenticación está usando la cuenta equivocada.
- La hora del dispositivo no está sincronizada.

## Qué probar

- Introduce el código más reciente que muestre tu aplicación de autenticación.
- Comprueba la hora en el dispositivo que genera los códigos.
- Asegúrate de que usas la entrada de cuenta correcta en la aplicación de autenticación.

Si todavía no puedes iniciar sesión, usa las opciones de recuperación si se guardaron cuando se activó la función.
