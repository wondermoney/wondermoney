---
title: Autenticación de dos factores
description: Añade un segundo paso al inicio de sesión con una aplicación de autenticación.
---

La autenticación de dos factores añade otra verificación cuando inicias sesión: después de tu contraseña, introduces el código de 6 dígitos de una aplicación de autenticación, o uno de tus códigos de respaldo.

Es especialmente útil cuando quieres una protección extra además de tu contraseña.

## Activarla

En la web:

1. Abre **Configuración**, elige **Seguridad** y busca **Autenticación de dos factores**.
2. Selecciona **Activar 2FA** e introduce la contraseña de tu cuenta.
3. Escanea el código QR con una aplicación de autenticación.
4. Guarda los códigos de respaldo que aparecen bajo el código QR. Selecciona **Copiar códigos** para copiarlos y guárdalos en un lugar al que puedas acceder sin el teléfono. Solo se muestran esta vez.
5. Selecciona **Continuar**, introduce el código de 6 dígitos que muestra la aplicación y selecciona **Enviar**.

En la aplicación móvil, abre **Más > Configuración > Seguridad** y selecciona **Activar la autenticación de dos factores**. Añade la clave de configuración a tu aplicación de autenticación, introduce el código de 6 dígitos que muestra y selecciona **Confirmar código**. Los códigos de respaldo se añadieron a la aplicación móvil después de la versión 1.0.3: una versión posterior también muestra los códigos de respaldo bajo la clave de configuración, con **Copiar códigos**. La versión 1.0.3 y las anteriores solo muestran la clave de configuración. La aplicación muestra su versión en la pantalla **Más**.

## Desactivarla

En la web, selecciona **Desactivar 2FA** en la misma sección e introduce la contraseña de tu cuenta. En la aplicación móvil, selecciona **Desactivar la autenticación de dos factores**.

## Iniciar sesión con un código de respaldo

Si no tienes tu aplicación de autenticación, selecciona **Usar un código de respaldo** en el paso de verificación del inicio de sesión e introduce uno de los códigos que guardaste. Cada código funciona una sola vez. Consulta [Autenticación de dos factores](/es/docs/start-here/multi-factor-authentication) para más detalles.

## Si pierdes tu aplicación de autenticación

1. Inicia sesión con uno de tus códigos de respaldo.
2. Abre **Configuración → Seguridad** y desactiva la autenticación de dos factores.
3. Vuelve a activarla con el dispositivo nuevo. Recibes un nuevo conjunto de códigos de respaldo; los anteriores dejan de funcionar.

## Problemas habituales

- El código ha caducado.
- La aplicación de autenticación está usando la cuenta equivocada.
- La hora del dispositivo no está sincronizada.
- Un código de respaldo ya se usó, o se escribió con las mayúsculas y minúsculas equivocadas.

## Qué probar

- Introduce el código más reciente que muestre tu aplicación de autenticación.
- Comprueba la hora en el dispositivo que genera los códigos.
- Asegúrate de que usas la entrada de cuenta correcta en la aplicación de autenticación.

Si todavía no puedes iniciar sesión, usa uno de los códigos de respaldo que guardaste cuando activaste la función.
