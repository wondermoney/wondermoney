---
title: Reglas
description: Categoriza, renombra, etiqueta u oculta transacciones automáticamente, comprueba qué coincide con una regla antes de guardarla, y aplícala a las transacciones que ya tienes.
---

Una regla le dice a WonderMoney qué hacer con las transacciones de cierto tipo: por ejemplo, "cuando la descripción contiene NETFLIX, asignar la categoría Entretenimiento". Las reglas pertenecen al hogar, así que ambos miembros ven y gestionan la misma lista.

## Dónde encontrarlas

En la web, ve a **Configuración → Reglas**. La lista muestra todas las reglas en el orden en que se ejecutan, con un resumen de una línea, como "Descripción contiene NETFLIX, asignar categoría Entretenimiento", y un interruptor para activar o desactivar cada regla.

- **Busca** por nombre, o **filtra** por la categoría que asigna la regla, para encontrar una regla rápidamente.
- **Reordena** arrastrando una regla, o con sus flechas arriba y abajo. Borra antes la búsqueda y el filtro: el orden siempre abarca la lista completa.
- **Edita** o **elimina** una regla desde su fila. Eliminar una regla no deshace lo que ya cambió.

## Crear una regla

Elige **Crear regla**, o empieza desde una transacción: abre su menú, elige **Editar** y luego **Crear regla**. Empezar desde una transacción rellena su comercio (o su descripción, si no tiene comercio) y su categoría actual.

Una regla tiene:

- **Condiciones.** Cada una compara un campo de la transacción:
  - **Descripción** o **Comercio**: contiene, no contiene, es, empieza por, termina en. La comparación ignora mayúsculas, acentos y espacios de más. En la descripción puedes comparar el texto como se muestra o el texto original del banco.
  - **Importe**: es, es mayor que, es al menos, es menor que, es como máximo, o está entre dos importes. Los importes se comparan sin signo; añade una condición de **Sentido** (entrada o salida de dinero) para distinguirlos.
  - **Cuenta**, **Categoría** (incluida "Sin categoría"), **Tipo de transacción** y **Moneda**: es una de, o no es ninguna de, los valores que elijas.
- **Cumplir todas las condiciones o cualquier condición.** Una regla puede tener hasta 20 condiciones.
- **Acciones**: asignar la categoría, asignar el comercio (elige uno o escribe un nombre nuevo), renombrar la descripción, añadir notas (solo donde las notas están vacías), añadir etiquetas, marcar como revisada u ocultar la transacción. Cada tipo de acción solo puede aparecer una vez en una regla.
- **Detenerse tras esta regla.** Cuando la regla coincide con una transacción, las reglas de debajo no se ejecutan sobre esa transacción.

Un hogar puede tener hasta 200 reglas.

## Sugerencias de reglas

Cuando corriges una y otra vez el mismo tipo de transacción, WonderMoney te propone una regla que lo haga por ti. Después de cambiar tú la categoría de una transacción, en la web o en la app, si ya has movido tres transacciones de este tipo a esa categoría en los últimos 90 días, te pregunta: "¿Categorizar siempre las transacciones de este tipo como Supermercado?"

- **De este tipo** quiere decir el mismo comercio, o el mismo comienzo de la descripción sin referencias ni números. "TRF MB WAY 912345678 JOAO" y "TRF MB WAY 913333333 ANA" empiezan ambas por "TRF MB WAY". Una cabecera de tarjeta como "COMPRA 1192" se omite, así que "COMPRA 1192 CONTINENTE" cuenta como "CONTINENTE".
- Cambiar varias transacciones a la vez cuenta cada una de ellas, y cada transacción cuenta una sola vez.
- Solo cuentan los cambios que haces tú. Los del otro miembro, una propuesta del asistente que confirmes y las categorías asignadas por una regla, por la categorización aprendida o por una importación no cuentan. Las transacciones de las cuentas privadas del otro miembro nunca cuentan.
- Elige **Crear regla** para abrir el editor de reglas ya rellenado, con su vista previa, y revísala antes de guardar. Elige **No volver a sugerir** para dejar de ver esa sugerencia. Si no eliges ninguna, puede volver a aparecer la próxima vez.

No aparece ninguna sugerencia cuando una regla activa ya da esa categoría a esas transacciones, o cuando WonderMoney ya las reconoce por la categoría que elegiste para su comercio. Esa categoría aprendida solo se reutiliza cuando la descripción de una transacción nueva es exactamente el nombre del comercio, así que la regla se sigue sugiriendo para descripciones con más texto.

## Vista previa antes de guardar

Mientras editas, la vista previa junto al formulario muestra cuántas de tus transacciones coinciden con la regla, cuántas de ellas cambiaría, y las 50 coincidencias más recientes con el cambio que recibiría cada una. Se actualiza poco después de que dejes de escribir.

La vista previa evalúa la regla sola y abarca las transacciones del hogar que puedes ver, incluidas las ocultas. Nunca muestra las cuentas privadas del otro miembro. Una coincidencia puede aparecer como **Sin cambios** cuando la transacción ya tiene esos valores, o cuando definiste ese valor tú mismo (ver abajo).

Guardar una regla no cambia las transacciones que ya tienes. Para cambiarlas también, aplica la regla (ver más abajo).

## Aplicar reglas a las transacciones existentes

Después de guardar una regla activa, WonderMoney comprueba cuántas de tus transacciones existentes cambiaría. Si hay alguna, te ofrece **Aplicar a N transacciones**. Confirma para aplicarla, o elige **Ahora no** para dejarlas como están.

Para ejecutar todas las reglas activas sobre las transacciones que ya tienes (por ejemplo, después de reordenarlas), elige **Aplicar a las transacciones existentes** arriba en **Configuración → Reglas**. Las reglas se ejecutan entonces de arriba abajo, como en las transacciones nuevas.

- El número que confirmas es exactamente lo que cambia al aplicar.
- La aplicación se ejecuta en segundo plano: el diálogo muestra el progreso, y puedes cerrarlo mientras se ejecuta. Al terminar, un mensaje te dice cuántas transacciones cambiaron.
- Abarca las transacciones del hogar que puedes ver, incluidas las ocultas, pero no las eliminadas ni las cuentas privadas del otro miembro. Todo lo que aparece en "Lo que las reglas nunca cambian" sigue valiendo.
- Aplicar la misma regla otra vez no cambia nada más. Cada cambio queda registrado en la actividad de la transacción.
- Solo una aplicación a la vez por hogar: espera a que termine una antes de empezar otra.

## Lo que las reglas nunca cambian

- Lo que definiste a mano: una categoría que elegiste, un comercio o una descripción que editaste, y notas que escribiste. La regla sigue contando como coincidencia, pero deja esos campos como están.
- El tipo de transacción. Solo la detección de transferencias marca una transacción como transferencia.
- Las transacciones de las cuentas privadas del otro miembro. Una regla actúa en nombre del miembro que cambió por última vez sus condiciones o acciones, y solo sobre las transacciones que ese miembro puede ver.

## Orden

Las reglas se ejecutan de arriba abajo. Cada regla mira la transacción tal como llegó, no como la dejaron las reglas anteriores. Cuando dos reglas asignan el mismo campo, gana la de abajo; las etiquetas de varias reglas se suman. Activa **Detenerse tras esta regla** para que las reglas de debajo no se ejecuten sobre lo que coincidió con ella.

## Exportar e importar reglas

Elige **Exportar** arriba en **Configuración → Reglas** para descargar las reglas del hogar en un archivo JSON. Elige **Importar** para cargar uno: WonderMoney revisa primero el archivo y muestra qué va a pasar antes de cambiar nada.

El archivo no contiene identificadores internos. Una regla nombra aquello a lo que se refiere: cuentas, comercios y etiquetas por su nombre, una categoría del sistema por su clave (el nombre sembrado, como `FOOD`) y una categoría tuya por su nombre. Eso es lo que le permite moverse a otra instancia.

```json
{
  "format": "wondermoney-rules",
  "version": 1,
  "rules": [
    {
      "name": "Streaming",
      "active": true,
      "match": "all",
      "stopProcessing": false,
      "conditions": [
        { "field": "merchant", "operator": "contains", "value": "netflix" },
        { "field": "account", "operator": "in", "values": ["Current account"] },
        { "field": "category", "operator": "in", "values": [{ "system": "ENTERTAINMENT" }] }
      ],
      "actions": [
        { "type": "set_category", "category": { "name": "Streaming" } },
        { "type": "set_merchant", "merchant": "Netflix" },
        { "type": "add_tags", "tags": ["Subscriptions"] }
      ]
    }
  ]
}
```

- Una categoría es `{ "system": "FOOD" }` para una categoría del sistema, `{ "name": "Streaming" }` para una tuya, o `"uncategorized"`.
- Los nombres de cuentas, comercios y etiquetas deben coincidir con los del hogar al que importas.
- El archivo puede contener hasta 1.000 reglas y ocupar como máximo 1 MB. El límite de 200 reglas por hogar sigue aplicándose.

**Modos de importación.** *Añadir* conserva las reglas que ya hay y añade las del archivo después. *Sustituir* elimina las reglas existentes y deja solo las del archivo, una vez validado el archivo entero; una importación fallida deja la lista como estaba. Ambos modos piden confirmación.

**La simulación.** Antes de escribir nada, la importación muestra las reglas que creará, las que omitirá porque ya existe una regla con ese nombre, y las referencias que no encontró. Después:

- Una categoría personalizada que falta se puede crear, si marcas la casilla.
- Una regla que nombra una cuenta que este hogar no tiene se importa desactivada, sin esa condición de cuenta.
- Una regla que nombra una categoría del sistema o una etiqueta que falta se omite.

Un archivo que no sea una exportación de reglas de WonderMoney, supere 1 MB o contenga más de 1.000 reglas se rechaza con un mensaje que explica por qué.
