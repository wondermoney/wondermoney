## Instalar con el script

```sh
curl -fsSLO https://github.com/wondermoney/wondermoney/releases/latest/download/install.sh
curl -fsSLO https://github.com/wondermoney/wondermoney/releases/latest/download/install.sh.sha256
sha256sum -c install.sh.sha256
sh install.sh
```

El script comprueba que estén Docker, el plugin Compose, `openssl` y `curl`, y se detiene con instrucciones si falta alguno. Descarga los archivos del servidor desde la etiqueta de la versión, escribe `.env` con secretos nuevos, inicia la pila y espera hasta tres minutos a la API. Pregunta las direcciones de la aplicación web y de la API; `--yes` usa los valores por defecto, `http://localhost:3000` y `http://localhost:3001`. Vuelve a ejecutarlo para actualizar: nunca reescribe `.env` y propone pasar a la última versión.

### Léelo primero

El instalador es un script POSIX `sh` corto. Descárgalo, léelo y después ejecútalo:

```sh
curl -fsSLO https://github.com/wondermoney/wondermoney/releases/latest/download/install.sh
less install.sh
sh install.sh
```

O haz los mismos pasos a mano, desde la etiqueta de la versión:

```sh
# v1.4.0: la versión que quieras
git clone --depth 1 --branch v1.4.0 https://github.com/wondermoney/wondermoney.git
cd wondermoney/apps/api/deploy/selfhost
./generate-env.sh
docker compose up -d
```

`generate-env.sh` escribe un archivo `.env` con secretos nuevos. Se ejecuta una sola vez: si `.env` ya existe, se detiene sin modificarlo, porque unos secretos nuevos cerrarían las sesiones existentes y dejarían ilegibles las credenciales bancarias guardadas. Guarda `.env` en un lugar seguro, junto con tus copias de seguridad.

En el primer arranque, la API crea la base de datos y carga los datos de referencia (monedas, categorías y el catálogo de activos). Esto tarda uno o dos minutos. Para seguirlo:

```sh
docker compose logs -f api
```

## Crear tu cuenta

Abre http://localhost:3000 y regístrate. La primera cuenta de una instancia nueva siempre puede registrarse. A partir de ahí, `SIGNUP_MODE` en el `.env` decide quién más puede hacerlo:

| Valor | Quién puede registrarse |
|---|---|
| `open` | Cualquier persona que pueda acceder a la aplicación web |
| `invite` | Solo personas invitadas a un hogar |
| `closed` | Nadie; las cuentas existentes siguen funcionando |

## Antes de configurar el correo

Mientras no haya un proveedor de correo configurado, los correos no se envían. Se escriben en el registro de la API, enlaces incluidos. Para recuperar una contraseña o aceptar una invitación mientras tanto:

```sh
docker compose logs api | grep "Email not sent"
```
