---
title: Crear una cartera
description: Crea una nueva cartera de inversión en WonderMoney.
---

Crea una cartera cuando quieras agrupar un conjunto de posiciones, transacciones y rentabilidad en una única vista de inversión.

## Cuándo crear una

- Usas más de un bróker o cuenta.
- Quieres separar la inversión a largo plazo del resto de posiciones.
- Gestionas estrategias diferentes y quieres vistas de rentabilidad separadas.

## Cómo crearla

1. Abre Inversiones de cartera.
2. Elige Crear cartera.
3. Introduce un nombre que corresponda a la cuenta o a la estrategia.
4. Elige la moneda que usa la cartera.
5. Guarda y después añade posiciones o importa transacciones.

## Buenos patrones de nombre

- El nombre del bróker más el tipo de cuenta, por ejemplo `DEGIRO Long Term`.
- El nombre de la estrategia, por ejemplo `ETF Core`.
- Una finalidad clara, por ejemplo `Jubilación` o `Ahorros de los hijos`.

## Errores comunes

- Reutilizar una misma cartera para objetivos sin relación.
- Elegir la moneda equivocada.
- Esperar a añadir datos hasta que la cartera esté totalmente completa. Puedes crearla primero y completarla después.
