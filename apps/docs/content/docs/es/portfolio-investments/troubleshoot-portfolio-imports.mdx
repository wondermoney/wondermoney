---
title: Resolver problemas de importación de cartera
description: Soluciona los problemas habituales de importación de CSV de cartera.
---

Si una importación falla o las cifras no parecen correctas, repasa las comprobaciones siguientes.

## Problemas habituales

- El archivo no es una exportación CSV del bróker.
- Faltan columnas obligatorias.
- Los tickers o los identificadores no coinciden con la lista de activos.
- Las mismas filas ya se importaron antes.
- La moneda o los separadores decimales no coinciden con el formato del archivo.

## Qué hacer

1. Vuelve a exportar el archivo desde el bróker.
2. Confirma que estás importando en la cartera correcta.
3. Revisa en la vista previa si hay duplicados o valores que faltan.
4. Corrige el archivo de origen si las fechas, las cantidades o las monedas son incorrectas.
5. Vuelve a ejecutar la importación solo cuando la vista previa tenga el aspecto correcto.

## Cuándo contactar con el soporte

Contacta con el soporte si el archivo es válido pero el importador lo rechaza igualmente, o si las filas se importan correctamente pero las posiciones resultantes son claramente incorrectas.
