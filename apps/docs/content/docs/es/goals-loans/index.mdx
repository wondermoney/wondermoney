Los objetivos y los préstamos te ayudan a hacer un seguimiento del dinero que tiene un propósito específico o una deuda concreta.

Usa esta sección para crear objetivos, planificar el pago de deudas, registrar préstamos o líneas de crédito, vincular cuentas como contexto y hacer un seguimiento de los reembolsos.

## Qué puedes hacer aquí

- Crea un objetivo de ahorro para el dinero que estás reservando, o un objetivo de amortización de deuda para las deudas que estás pagando.
- Ordena los objetivos por prioridad en tus listas.
- Revisa los objetivos archivados y restáuralos cuando lo necesites.
- Añade un préstamo o una línea de crédito para las deudas que quieras controlar.
- Vincula un objetivo a una cuenta como contexto.
- Asigna dinero a un objetivo dentro del límite de disponible para asignar de tu presupuesto.
- Registra reembolsos de un préstamo.

## Cómo funciona

Los objetivos son reservas respaldadas por el presupuesto. Indican para qué es el dinero, no en qué cuenta está. Asignar dinero a un objetivo está limitado por lo que hay disponible en tu [presupuesto](/es/docs/budgets/); el límite de disponible para asignar muestra este límite antes de que asignes. Las entradas de préstamo te ayudan a controlar cuánto debes y cómo los reembolsos cambian el saldo con el tiempo.

Para definiciones sencillas de los términos del presupuesto, consulta el [glosario](/es/docs/glossary).

## Errores comunes

- Esperar que un vínculo de objetivo mueva dinero automáticamente.
- Tratar los vínculos de cuentas como un registro oficial de saldo o de transferencias.
- Mezclar el progreso de un objetivo con los saldos de las cuentas bancarias.
- Usar el módulo para planificar rendimientos de inversiones. Es para objetivos y deudas, no para proyecciones.
