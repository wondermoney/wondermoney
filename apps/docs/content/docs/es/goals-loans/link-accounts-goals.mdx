---
title: Vincular cuentas a objetivos
description: Añade un vínculo de cuenta para mostrar dónde se suele guardar un objetivo.
---

Vincula una cuenta a un objetivo cuando quieras un recordatorio útil de dónde se suele guardar ese dinero.

## Qué hace el vínculo

- Muestra información contextual en el objetivo.
- Te ayuda a recordar dónde se suele guardar el dinero.
- No cambia el progreso del objetivo ni el saldo disponible.

## Qué no hace el vínculo

- No bloquea dinero en la cuenta.
- No asigna dinero automáticamente.
- No mueve fondos entre cuentas.

## Errores comunes

- Tratar el vínculo como contabilidad.
- Usarlo para hacer un seguimiento de transferencias.
- Añadir vínculos activos duplicados para la misma cuenta y el mismo objetivo.
