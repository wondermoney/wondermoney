---
title: Crear un objetivo
description: Configura un objetivo para ahorrar o para pagar deudas.
---

Crea un objetivo cuando quieras reservar dinero para un propósito específico, como un fondo de emergencia, un viaje, los impuestos o una compra futura, o cuando quieras planificar el pago de una o más deudas.

## Elige un tipo de objetivo

Cuando crees un objetivo, elige primero el tipo:

- **Ahorro** reserva dinero hacia un importe objetivo, como un fondo de emergencia o una compra futura.
- **Amortización de deuda** hace un seguimiento del progreso hacia el pago de una o más deudas.

El tipo de objetivo forma parte de la configuración del objetivo. Una vez que comiencen las aportaciones, el tipo y el importe objetivo quedan bloqueados y no se pueden cambiar.

## Objetivos de ahorro

Para un objetivo de ahorro, configura:

- Nombre del objetivo
- Importe objetivo
- Fecha objetivo, si tienes una
- Aportación mensual objetivo, si quieres una

## Objetivos de amortización de deuda

Para un objetivo de amortización de deuda, elige qué deudas incluir y cómo deben ordenarse.

Elige la estrategia de ordenación:

- **Método avalancha** — ordena las deudas por tipo de interés, de mayor a menor. Esto normalmente minimiza el interés total pagado.
- **Método bola de nieve** — ordena las deudas por saldo, de menor a mayor. Esto normalmente elimina los saldos más pequeños antes.

Define una fecha de pago objetivo si tienes una. El objetivo muestra el calendario de pago proyectado para tu estrategia y lo compara con la alternativa, para que puedas ver cómo la elección cambia el interés total y la fecha de pago.

## Prioridad

Define la prioridad en el formulario de creación o de edición. Los objetivos con una prioridad más alta aparecen primero en las listas de objetivos. Puedes cambiar la prioridad más adelante. Consulta [Prioridad de los objetivos](/es/docs/goals-loans/goal-priority) para más detalles.

## Asignar dinero

El objetivo guarda un importe objetivo y hace un seguimiento del progreso mediante la actividad del objetivo. No mueve dinero entre cuentas bancarias. Puedes asignar dinero al objetivo manualmente y después financiar un gasto con él cuando lo necesites.

Cuando asignas dinero, el límite de disponible para asignar limita la cantidad que puedes asignar según tu presupuesto. No puedes asignar más del límite. Aparece un mensaje de confirmación cuando la asignación se realiza correctamente.

## Buenos nombres para objetivos

- Fondo de emergencia
- Impuestos anuales
- Portátil nuevo
- Vacaciones 2026

## Errores comunes

- Definir un importe objetivo que no coincide con el propósito real del dinero.
- Crear demasiados objetivos pequeños que son difíciles de gestionar.
- Esperar que el objetivo reserve dinero automáticamente de una cuenta bancaria.
- Elegir una estrategia de amortización de deuda sin comparar antes el calendario de pago.
