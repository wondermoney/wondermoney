El área de Mercados Financieros es la zona de investigación de acciones, ETFs y otros instrumentos cotizados. Está disponible para todos los usuarios.

Úsala para buscar activos, revisar el precio y el historial de precios de un activo y guardar elementos en una lista de seguimiento.

## Qué puedes hacer aquí

- Buscar un activo por ticker, nombre o palabra clave.
- Abrir la página de un activo para revisar su precio, la variación del día y el historial de precios.
- Guardar instrumentos en una lista de seguimiento que se almacena en tu cuenta y se sincroniza entre dispositivos.

## Nota sobre los datos

Los datos de mercado sirven solo para investigación y seguimiento. WonderMoney no ofrece asesoramiento de inversión.

Los datos fundamentales, los datos financieros, los resultados y las noticias de mercado no forman parte del plan de datos de mercado que usa WonderMoney hoy. Los paneles de datos fundamentales, datos financieros y resultados de la página de un activo lo indican; los precios, el historial de precios y el perfil de la empresa no se ven afectados.

Cuando no hay cotización en tiempo real para un activo, su página muestra el último cierre y su fecha.

Los servicios de datos de mercado tienen límites de peticiones. Cuando un proveedor no está disponible, las vistas afectadas siguen mostrando las últimas cifras disponibles en lugar de fallar.

## Errores comunes

- Usar un único dato para decidir una compra o una venta.
- Confundir las listas de seguimiento con las carteras. Una lista de seguimiento es investigación; una [cartera](/es/docs/portfolio-investments) es el registro de lo que tienes.
- Asumir que todas las cifras de mercado se actualizan exactamente al mismo tiempo.
