## Cómo funciona la búsqueda

- La búsqueda encuentra coincidencias por ticker, nombre de activo y palabra clave.
- En la web, una coincidencia exacta del ticker ocupa el primer puesto, seguida de las cotizaciones en la bolsa de origen, cuyo ticker no lleva sufijo de bolsa.
- Los resultados se actualizan mientras escribes. El campo espera un breve momento después de que dejes de escribir antes de obtener nuevos resultados: una quinta parte de segundo en la web, alrededor de un tercio de segundo en la aplicación móvil.

## Comportamiento de la búsqueda

- Usa el teclado para desplazarte por los resultados y pulsa Intro para seleccionar uno.
- Al enfocar el campo de búsqueda, cualquier texto existente queda seleccionado, así que puedes empezar a escribir y reemplazarlo directamente en lugar de borrarlo a mano.
- Un campo de búsqueda vacío es seguro: no se muestran resultados ni se produce ningún error. Escribe unos pocos caracteres para ver las coincidencias.

## Consejos de búsqueda

- Busca primero por ticker si lo conoces.
- Prueba con el nombre del activo si el ticker no es evidente.
- Usa palabras clave amplias cuando estés explorando un mercado o un sector.

## Para qué sirven los resultados

- Abrir la página de detalle del activo.
- Añadir un activo a tu lista de seguimiento.
- Comprobar los datos de mercado antes de importarlos a una cartera.

La página de un activo muestra su precio, la variación del día y el historial de precios. Los paneles de datos fundamentales, datos financieros y resultados indican, por ahora, que esos datos no forman parte del plan de datos de mercado que usa WonderMoney hoy.

## Errores comunes

- Elegir la clase de acción o el mercado de cotización equivocados.
- Asumir que nombres similares corresponden a activos idénticos.
- Usar los resultados de búsqueda como señal de compra o venta.
