Esta sección tiene una página breve para cada versión de WonderMoney, escrita para quienes la usan: qué hay de nuevo, qué se corrigió, qué necesita un servidor propio antes de actualizarse y quién contribuyó. Las [versiones en GitHub](https://github.com/wondermoney/wondermoney/releases) tienen la lista completa de cambios y los archivos que descarga el instalador.

Las versiones publicadas antes de que existiera esta sección solo están descritas en GitHub.

## Qué incluye cada página

- **Actualizar** va primero: todo lo que necesita una instancia propia, como migraciones de la base de datos, ajustes nuevos o modificados, o un comando que ejecutar después de actualizar. Si usas el servicio alojado, no tienes que hacer nada.
- **Nuevo** enumera las funciones y los cambios que vas a notar.
- **Correcciones** enumera los problemas corregidos.
- **Agradecimientos** nombra a todas las personas con una pull request en la versión y señala a quienes contribuyen por primera vez.

## Qué versión tienes

El menú de la cuenta en la aplicación web (o **Más** en la aplicación móvil) muestra la versión de la aplicación web y la del servidor. Para actualizar una instancia propia, sigue [Actualizaciones y copias de seguridad](/es/docs/self-hosting/upgrade-and-backup).
