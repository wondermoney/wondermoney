## Síntomas

Usa esta sección cuando veas un error, datos que faltan o un flujo que se detiene de forma inesperada.

Los síntomas más comunes son:

- El inicio de sesión no se completa
- Un banco no se vuelve a conectar
- Un presupuesto no se guarda
- Un archivo de importación no se sube

## Qué comprobar

Empieza por las comprobaciones más sencillas:

- Confirma que la página se ha actualizado correctamente
- Asegúrate de que usas el espacio de trabajo o la cuenta correctos
- Comprueba si el problema es temporal
- Revisa el artículo de ayuda correspondiente a la función

## Qué probar

Prueba la guía que corresponde a tu tipo de problema:

- [Problemas de inicio de sesión](/es/docs/troubleshooting/sign-in-problems) — el flujo de inicio de sesión no se completa.
- [Problemas de conexión bancaria](/es/docs/troubleshooting/bank-connection-problems) — incidentes de conexión, incluidos los estados que se recuperan solos.
- [Problemas de configuración del presupuesto](/es/docs/troubleshooting/budget-setup-problems) — un presupuesto no se guarda o muestra totales inesperados.
- [Problemas de importación de transacciones](/es/docs/troubleshooting/transaction-import-problems) — gestión de duplicados y tolerancia a transacciones similares después de una importación.
- [Problemas de importación de cartera](/es/docs/troubleshooting/portfolio-import-problems) — un archivo de cartera no se importa o se importa con valores incorrectos.

Si el problema no está claro, delimítalo por función y mensaje de error.

## Cuándo contactar con soporte

Contacta con soporte si el problema continúa después de las comprobaciones básicas o si necesitas ayuda con datos específicos de tu cuenta.
