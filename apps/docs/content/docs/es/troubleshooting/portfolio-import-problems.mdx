description: Pasos para diagnosticar problemas de importación de cartera en WonderMoney.
---

## Síntomas

- Un archivo de cartera no se sube.
- Las posiciones importadas muestran una cantidad o un precio incorrectos.
- Las transacciones aparecen incompletas después de la importación.
- La importación indica una columna o un formato de fecha no compatible.

## Qué comprobar

- Si el archivo usa el formato esperado.
- Si la fecha de la cartera y la moneda son correctas.
- Si el archivo incluye posiciones divididas o ajustes que requieren un tratamiento especial.
- Si la exportación de origen está completa.

## Qué probar

1. Exporta el archivo de nuevo desde la plataforma de origen.
2. Confirma que las columnas coinciden con la plantilla de importación.
3. Elimina filas de más, notas o celdas combinadas.
4. Prueba primero a importar un archivo de muestra más pequeño.

## Cuándo contactar con soporte

Contacta con soporte si el archivo es válido pero la cartera sigue importándose con valores incorrectos, o si la importación falla con datos que parecen correctos.
