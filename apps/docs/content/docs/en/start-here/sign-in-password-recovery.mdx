Use the sign-in form with the email and password tied to your WonderMoney account. If you cannot access the account, use the recovery flow before creating a new profile.

## Before you start

Have access to the inbox for your registered email address. If multi-factor authentication is enabled, keep the verification device nearby.

## Steps

1. Open the sign-in page.
2. Enter your email address and password, and select **Sign in**.
3. If two-factor authentication is on, enter the six-digit code from your authenticator app.
4. If you forgot the password, select **Forgot your password?**, enter your email address and select **Send reset email**. Follow the link in the email and choose a new password.

## Other ways to sign in

- **Sign in with a passkey** uses your fingerprint, face or device PIN, with no password and no authenticator code. Add one first in **Settings → Security**; see [Passkeys](/en/docs/settings-security-privacy/passkeys).
- **Google**, under **Or continue with**, and Apple in the mobile app, where the server offers them.
- Single sign-on, on a self-hosted server set up for it. See [Single sign-on](/en/docs/self-hosting/single-sign-on).
- **Try the demo** opens a shared, read-only sample household without an account, on a server that offers the demo.

## Review access

After you sign in, confirm that the dashboard loads with the right user profile. If you changed your password, sign in again on any other devices you use.

## Common issues

- The password reset email is delayed or filtered.
- The email address does not match the account.
- MFA codes have expired or were entered too late.
- A saved browser session is pointing to an older account.
