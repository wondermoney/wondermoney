## What this help center covers

- Start here: create an account, pick your country, connect a bank or add an offline account, sign in, recover access, set up MFA, and read the dashboard.
- Accounts and transactions: bank connections, manual accounts, transaction review, categorisation, recurring payments, and CSV imports.
- Budgets: create a first budget, choose categories, and track monthly spending.

## Recommended setup path

1. [Create an account](/en/docs/start-here/create-account) and pick your country.
2. In the account step, [connect a bank inline](/en/docs/start-here/connect-first-bank-account) or [add an offline account](/en/docs/accounts-transactions/manual-offline-account).
3. [Understand transactions](/en/docs/accounts-transactions/understand-transactions) so spending is categorized correctly.
4. [Create your first budget](/en/docs/budgets/create-first-budget) using the [envelope method](/en/docs/budgets/envelope-method).
5. [Create a portfolio](/en/docs/portfolio-investments/create-portfolio) if you want investments included in net worth.

Use the troubleshooting pages when a flow stops part way through, or when imported data does not match what you expected.

WonderMoney uses the same core model across the app: sign in to access your account, connect bank accounts to bring in transactions, and build budgets and portfolio views from your linked data. Reaching the final onboarding step marks your first run complete, so the dashboard renders normally on the next sign-in.
