## Download and start

```sh
git clone --depth 1 https://github.com/wondermoney/wondermoney.git
cd wondermoney/apps/api/deploy/selfhost
./generate-env.sh
docker compose up -d
```

`generate-env.sh` writes a `.env` file with fresh secrets. It runs once: if `.env` already exists it stops without changing it, because new secrets would end existing sessions and make stored bank credentials unreadable. Keep `.env` safe, with your backups.

On the first start, the API creates the database and loads the reference data (currencies, categories and the asset catalogue). This takes a minute or two. To follow it:

```sh
docker compose logs -f api
```

## Create your account

Open http://localhost:3000 and sign up. The first account on a new instance can always sign up. After that, `SIGNUP_MODE` in `.env` decides who else can:

| Value | Who can sign up |
|---|---|
| `open` | Anyone who can reach the web app |
| `invite` | Only people invited to a household |
| `closed` | Nobody; existing accounts keep working |

## Before you set up email

Until an email provider is configured, emails are not sent. They are written to the API log, links included. To reset a password or accept an invite in the meantime:

```sh
docker compose logs api | grep "Email not sent"
```
