Link an account to a goal when you want a helpful reminder of where that money is usually kept.

## What the link does

- Shows contextual information on the goal.
- Helps you remember where the money is usually held.
- Does not change goal progress or available balance.

## What the link does not do

- It does not lock money in the account.
- It does not assign money automatically.
- It does not move funds between accounts.

<DocsImage
  src="/images/docs/goals-loans/link-accounts-goals-link-account.png"

## Common mistakes

- Treating the link as bookkeeping.
- Using it to track transfers.
- Adding duplicate active links for the same account and goal.
