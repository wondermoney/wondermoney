Priority controls how goals are ordered in your lists.

## What priority does

Goals are ordered by priority, highest first. It keeps the goals that matter most visible without removing the others.

## How to set it

Set the priority when you create a goal, or change it later when you edit the goal. The current priority is shown on the goal card.

## Where ordering applies

Active goals are ordered by priority in goal lists. Archived goals keep their priority but only appear in the archived view.

## Common mistakes

- Using priority instead of archiving for goals you no longer track.
- Setting the same priority for many goals, which makes the order less useful.
