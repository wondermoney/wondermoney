title: WonderMoney 1.7.0
description: Redesigned calculator and feature pages on wonder.money, new menus in its header, and web analytics that no longer carry identifiers.
---

[Release notes on GitHub](https://github.com/wondermoney/wondermoney/releases/tag/v1.7.0)

## Upgrading

Nothing to do. This release has no migrations and no new settings.

## New

- **Website menus:** the wonder.money header has a menu for every feature, the free tools grouped with icons, and a separate menu for the comparators.
- **Feature pages:** six new pages on wonder.money, including households, importing, bills, the AI assistant, multiple currencies and self-hosting. The existing feature pages have wider explanations with illustrations.
- **Calculator pages:** every free calculator on wonder.money has been redesigned. The guide is wider and "How to read the result" is easier to scan. The worked example is drawn as cards with icons and values, and each part of a formula links to its note.

## Fixes

- The website's dropdowns and fields share one look, the footer language picker's arrow no longer touches the edge, and the saved privacy-choices message is no longer cramped.

## Privacy

- The web app no longer sends account, budget, transaction or bank-connection identifiers, or the contents of a submitted receipt form, with analytics events. A last check drops any identifier or personal value before an event leaves your browser. See [Data Privacy](/en/docs/settings-security-privacy/data-privacy).
