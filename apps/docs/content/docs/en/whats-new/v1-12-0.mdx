## Upgrading

Nothing to do. There are no migrations and no new settings, and a server that already has accounts looks the same as before.

## New

- **First-run setup.** A new server opens on a setup page instead of the login page. It welcomes you by the server's name, creates the first account and shows which features the server has turned on, with links to the guide for the rest. Then the usual onboarding begins.
- **The first account is the server's admin.** It can open the admin pages without running a script. With single sign-on admin groups set, the groups still decide (see [Single sign-on](/en/docs/self-hosting/single-sign-on)). Finish setup before you expose a new server to the internet: until then, whoever opens it first becomes its admin.
