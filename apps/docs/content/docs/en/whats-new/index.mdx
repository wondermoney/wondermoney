This section has a short page for each WonderMoney release, written for the people who use it: what is new, what was fixed, what a self-hosted server needs before it upgrades, and who contributed. The [releases on GitHub](https://github.com/wondermoney/wondermoney/releases) have the full list of changes and the files the installer downloads.

Releases published before this section existed are described only on GitHub.

## What each page covers

- **Upgrading** comes first: anything a self-hosted instance needs, such as database migrations, new or changed settings, or a command to run after updating. If you use the hosted service, there is nothing to do.
- **New** lists the features and changes you will notice.
- **Fixes** lists the problems that were fixed.
- **Thanks to** names everyone whose pull request is in the release, and marks first-time contributors.

## Which version you have

The web app's account menu (or **More** in the mobile app) shows the version of the web app and of the server. To update a self-hosted instance, follow [Updates and backups](/en/docs/self-hosting/upgrade-and-backup).
