title: Preview features
description: Try features before they are ready for everyone.
---

Preview features are unfinished parts of WonderMoney that you can turn on to try early. They are off by default, and you can turn them off again at any time.

## Turn preview features on or off

- **Web:** Settings › Appearance › Preview features.
- **Mobile:** More › Settings › Appearance › Preview features.

The switch is stored on your account, so the same choice applies on web and mobile. It is personal to you: turning it on does not change what anyone else in your household sees.

## What to expect

Preview features may change, break or be removed without notice. They are not held to the same stability expectations as the rest of the app. If something goes wrong, turn the switch off; the regular app is unchanged.

## Where preview features appear

A preview entry point is marked with a small **Preview** tag. Without preview features on, those entry points are hidden. The server also refuses the related requests, so a link you saved earlier will not open the feature.

## What to check

- Whether the switch is on for the account you are signed in with.
- Whether the feature is available on this server; a self-hosted instance may not include it.
- Whether the entry point is marked **Preview**; a feature without the tag is not gated.
