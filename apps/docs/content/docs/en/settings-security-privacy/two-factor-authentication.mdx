Two-factor authentication adds another check when you sign in: after your password, you enter the 6-digit code from an authenticator app, or one of your backup codes.

It is most useful when you want extra protection on top of your password.

## Turn it on

On the web:

1. Open **Settings**, choose **Security** and find **Multi-factor authentication**.
2. Select **Enable 2FA** and enter your account password.
3. Scan the QR code with an authenticator app.
4. Save the backup codes shown under the QR code. Select **Copy codes** to copy them, and keep them somewhere you can reach without your phone. They are shown only this once.
5. Select **Continue**, enter the 6-digit code the app shows, and select **Submit**.

In the mobile app, open **More > Settings > Security** and select **Turn on two-factor authentication**. Add the setup key to your authenticator app, enter the 6-digit code it shows, and select **Confirm code**. From an upcoming app release, the mobile app also shows the backup codes under the setup key, with **Copy codes**.

## Turn it off

On the web, select **Disable 2FA** in the same section and enter your account password. In the mobile app, select **Turn off two-factor authentication**.

## Sign in with a backup code

If you don't have your authenticator app, select **Use a backup code** on the sign-in verification step and enter one of your saved codes. Each code works once. See [Multi-factor authentication](/en/docs/start-here/multi-factor-authentication) for the details.

## If you lose your authenticator app

1. Sign in with one of your backup codes.
2. Open **Settings → Security** and turn two-factor authentication off.
3. Turn it on again with the new device. This gives you a new set of backup codes; the old ones stop working.

## Common issues

- The code has expired.
- The authenticator app is using the wrong account.
- The device time is out of sync.
- A backup code was already used, or was typed with the wrong upper and lower case.

## What to try

- Enter the most recent code shown by your authenticator app.
- Check the time on the device that generates codes.
- Make sure you are using the correct account entry in the authenticator app.

If you still cannot sign in, use one of the backup codes you saved when you turned the feature on.
