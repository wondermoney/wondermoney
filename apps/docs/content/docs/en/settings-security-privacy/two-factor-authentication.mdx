Two-factor authentication adds another check when you sign in.

It is most useful when you want extra protection on top of your password.

## Turn it on

On the web:

1. Open **Settings**, choose **Security** and find **Multi-factor authentication**.
2. Select **Enable 2FA** and enter your account password.
3. Scan the QR code with an authenticator app. Store the backup codes shown below it somewhere safe; **Copy codes** copies them. Each one can be used once if you lose access to your authenticator app.
4. Select **Continue**, enter the 6-digit code the app shows, and select **Submit**.

In the mobile app, open **More > Settings > Security** and select **Turn on two-factor authentication**. Add the setup key to your authenticator app, enter the 6-digit code it shows, and select **Confirm code**.

## Turn it off

On the web, select **Disable 2FA** in the same section and enter your account password. In the mobile app, select **Turn off two-factor authentication**.

## Common issues

- The code has expired.
- The authenticator app is using the wrong account.
- The device time is out of sync.

## What to try

- Enter the most recent code shown by your authenticator app.
- Check the time on the device that generates codes.
- Make sure you are using the correct account entry in the authenticator app.

If you still cannot sign in, use recovery options if they were saved when the feature was enabled.
