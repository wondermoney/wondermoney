## Symptoms

Use this section when you see an error, missing data, or a flow that stops unexpectedly.

Common symptoms include:

- Sign-in does not complete
- A bank does not reconnect
- A budget does not save
- An import file does not upload

## What to check

Start with the simplest checks:

- Confirm the page refreshed correctly
- Make sure you are using the right workspace or account
- Check whether the issue is temporary
- Review the relevant help article for the feature

## What to try

Try the matching guide for your issue type:

- [Sign-in problems](/en/docs/troubleshooting/sign-in-problems) — the sign-in flow does not complete.
- [Bank connection problems](/en/docs/troubleshooting/bank-connection-problems) — connection incidents, including states that recover on their own.
- [Budget setup problems](/en/docs/troubleshooting/budget-setup-problems) — a budget does not save or shows unexpected totals.
- [Transaction import problems](/en/docs/troubleshooting/transaction-import-problems) — duplicate handling and similar-transaction tolerance after an import.
- [Portfolio import problems](/en/docs/troubleshooting/portfolio-import-problems) — a portfolio file does not import or imports with wrong values.

If the issue is not clear, narrow it down by feature and error message.

## When to contact support

Contact support if the problem persists after basic checks or if you need help with account-specific data.
