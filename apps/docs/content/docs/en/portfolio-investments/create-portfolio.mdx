Create a portfolio when you want to group a set of holdings, transactions, and performance into one investment view.

## When to create one

- You use more than one broker or account.
- You want to separate long-term investing from other holdings.
- You manage different strategies and want separate performance views.

## How to create it

1. Open Portfolio investments.
2. Choose Create portfolio.
3. Enter a name that matches the account or strategy.
4. Pick the currency used by the portfolio.
5. Save, then add holdings or import transactions.

## Good naming patterns

- Broker name plus account type, such as `DEGIRO Long Term`.
- Strategy name, such as `ETF Core`.
- A clear purpose, such as `Retirement` or `Kids savings`.

## Common mistakes

- Reusing one portfolio for unrelated goals.
- Choosing the wrong currency.
- Waiting to add data until the portfolio is fully complete. You can create it first and fill it later.
