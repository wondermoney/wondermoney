Portfolio benchmarks help you compare your holdings against a reference index or other market baseline.

This view is informational only. WonderMoney does not tell you what to buy, sell, or hold.

## What this view shows

- Portfolio return over time.
- Benchmark return over the same period.
- Relative performance between the two.

## How to read it

- A benchmark is a comparison line, not a recommendation.
- Compare [return](/en/docs/glossary#return), [benchmark](/en/docs/glossary#benchmark), and [time range](/en/docs/portfolio-investments/portfolio-metrics-explained#time-range) together.
- Check whether fees, dividends, and [currency effects](/en/docs/glossary#currency-effect) are included in the figures shown.
- Use the same currency context when possible.

## Common mistakes

- Comparing short periods as if they were meaningful long-term results.
- Treating benchmark lag as proof that one asset is better.
- Using a benchmark with a very different risk profile from the portfolio.
