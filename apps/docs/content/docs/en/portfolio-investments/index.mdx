## What you can do here

- Create one or more portfolios for different brokers, accounts, or strategies.
- Add buys, sells and other portfolio transactions, with their fees.
- Import holdings and transactions from a broker CSV.
- Review allocation by asset and compare performance against a benchmark.
- See which holdings moved the most over a period: [Top Movers](/en/docs/portfolio-investments/performance-benchmarks#top-movers).
- Read the annual yield, volatility, Sharpe ratio, max drawdown and risk level of your portfolios: [Advanced metrics](/en/docs/portfolio-investments/portfolio-metrics-explained#advanced-metrics).
- See upcoming dividend dates for the securities you hold: [Dividends and income](/en/docs/portfolio-investments/portfolio-metrics-explained#upcoming-dividends-in-the-calendar).
- Set a target allocation for a portfolio and see how far it has drifted: [Holdings allocation](/en/docs/portfolio-investments/holdings-allocation#target-allocation).
- Record Portuguese savings certificates (Certificados de Aforro) beside stocks and ETFs: [Add portfolio transactions](/en/docs/portfolio-investments/add-portfolio-transactions#savings-certificates).
- In a household, filter the whole Portfolios page by member: [Filter by member](/en/docs/household/filter-by-member).
- Count a home, a vehicle or a valuable at a value you set: [Homes, vehicles and other assets](/en/docs/portfolio-investments/manual-assets).
- Count Bitcoin and Ethereum held at public addresses, valued once a day, when your server has them turned on: [Crypto wallets](/en/docs/portfolio-investments/crypto-wallets).

## How it works

Portfolio data in WonderMoney is import-based. Most European brokers do not provide usable account APIs, so you add data manually through CSV import or transaction entry.

Once holdings are in the app, market prices update once a day on weekdays and portfolio values refresh automatically.

## Before you start

- Make sure your broker export includes the columns needed for holdings or transactions.
- Use the same currency for the portfolio as the underlying data where possible.
- If you manage several strategies, create a separate portfolio for each one.

## Common mistakes

- Mixing holdings from unrelated accounts into one portfolio.
- Importing the same CSV twice.
- Expecting broker balance data to match portfolio value exactly when trades have not been imported yet.
- Using portfolio pages as financial advice. They show data only.
