## Common issues

- The file is not a CSV, XLS or XLSX export from the broker.
- Required columns are missing.
- Tickers or identifiers do not match the asset list.
- The same rows were imported earlier.
- Currency or decimal separators do not match the file format.

## What to do

1. Re-export the file from the broker.
2. Confirm you are importing into the correct portfolio.
3. Check the preview for duplicates or missing values.
4. Fix the source file if dates, quantities, or currencies are wrong.
5. Re-run the import only after the preview looks correct.

## When to contact support

Contact support if the file is valid but the importer still rejects it, or if rows import successfully but the resulting holdings are clearly wrong.
